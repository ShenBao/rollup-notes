# plugin-terser

@rollup/plugin-terser 是 Rollup 官方提供的一个插件，用于在构建过程中使用 Terser 对 JavaScript 代码进行压缩（minify）。它是 rollup-plugin-terser 的官方继任者，使用更现代的 API，并与 Rollup v3+ 兼容良好。

```bash
npm install @rollup/plugin-terser --save-dev
```

```js
terser({
  // 是否保留注释（默认 false）
  keep_fnames: false,
  // 自定义压缩选项
  compress: {
    drop_console: true, // 移除 console 语句
    drop_debugger: true,
    pure_funcs: ['console.log'] // 视为无副作用的函数，可被移除
  },
  // 自定义格式化选项（通常用于美化，但 minify 时很少用）
  format: {
    comments: false
  },
  // 是否生成 source map（通常由 Rollup 控制）
  sourceMap: true // 若 Rollup output.sourcemap 为 true，则建议设为 true
})
```

```js
// rollup.config.js
import terser from '@rollup/plugin-terser';

export default {
  input: 'src/index.js',
  output: {
    file: 'dist/index.min.js',
    format: 'iife',
    name: 'MyLib',
    sourcemap: true
  },
  plugins: [
    terser({
      compress: {
        drop_console: true
      },
      format: {
        comments: false
      },
      sourceMap: true
    })
  ]
};
```

注意事项:
- 该插件应在其他转换插件（如 @rollup/plugin-babel、@rollup/plugin-typescript）之后使用，以确保压缩的是最终生成的 JS 代码。
- 不要与 rollup-plugin-uglify 或旧版 rollup-plugin-terser 混用。
- 如果你使用 TypeScript，确保先用 @rollup/plugin-typescript 编译，再压缩。
