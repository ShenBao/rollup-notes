# plugin-sucrase

@rollup/plugin-sucrase 是一个用于 Rollup 的插件，它使用 Sucrase 作为快速的 TypeScript、JSX、Flow 等语法的转换器，不进行类型检查，仅做语法转换，因此构建速度非常快，适合开发环境或对类型检查不敏感的场景。

```bash
npm install --save-dev @rollup/plugin-sucrase sucrase
```

插件通过 sucrase 函数导出，接收一个配置对象：

```js
import sucrase from '@rollup/plugin-sucrase';

export default {
  input: 'src/index.ts',
  output: {
    file: 'dist/bundle.js',
    format: 'esm'
  },
  plugins: [
    sucrase({
      // 可选：指定要转换的文件扩展名（默认包含 .ts, .tsx, .jsx）
      include: ['**/*.ts', '**/*.tsx'],
      exclude: ['node_modules/**'],

      // 转换目标语法（可选）
      transforms: ['typescript', 'jsx'], // 默认会根据文件扩展名自动推断

      // 其他 Sucrase 选项（透传给 sucrase.transform）
      production: true, // 是否移除开发专用代码（如 __DEV__）
      disableESTransforms: false, // 是否禁用 ES 新语法转换（如可选链）
    })
  ]
};
```

常用 transforms 类型
- 'typescript'：转换 .ts / .tsx
- 'jsx'：转换 JSX 语法
- 'flow'：转换 Flow 类型注解
- 'imports'：将 ES Modules 转为 CommonJS（一般不需要，Rollup 自己处理模块）
- 'react-hot-loader'：支持 React Hot Loader（已过时）

注：通常只需指定 'typescript' 和 'jsx'。 


## 示例：构建 React + TypeScript 项目

```js
// rollup.config.js
import sucrase from '@rollup/plugin-sucrase';

export default {
  input: 'src/main.tsx',
  output: {
    file: 'dist/app.js',
    format: 'iife'
  },
  plugins: [
    sucrase({
      transforms: ['typescript', 'jsx']
    })
  ]
};
```

注意事项
- 不进行类型检查：如需类型检查，请额外运行 tsc --noEmit。
- 不支持高级 TypeScript 功能：如 const enum、某些装饰器语法等。
- 仅语法转换：例如 import/export 由 Rollup 处理，Sucrase 不会转换模块语法（除非你显式开启 'imports'，但通常不需要）。
- 适合开发环境：因其速度优势；生产环境若需兼容旧浏览器，可能仍需 Babel。
