# plugin-run

@rollup/plugin-run 是 Rollup 官方提供的一个插件，主要用于在构建完成后自动运行生成的 bundle 文件。它的典型使用场景包括：

1. 本地开发快速测试
当你在开发一个 Node.js 应用或脚本时，每次修改源码后希望自动重新构建并立即运行输出结果，而无需手动执行 node dist/bundle.js。配合 rollup --watch 使用，可以实现“保存即运行”的开发体验。

2. 构建并立即执行脚本
适用于一次性脚本、工具类程序（CLI 工具原型、数据处理脚本等），在构建后自动执行以查看输出或副作用（如生成文件、调用 API 等）。

3. 简化开发工作流
避免在终端中频繁切换命令（如先 rollup -c 再 node ./dist/main.js），通过插件一步完成构建 + 运行。

```js
// rollup.config.js
import run from '@rollup/plugin-run';

export default {
  input: 'src/main.js',
  output: {
    file: 'dist/bundle.js',
    format: 'cjs' // 必须是 Node.js 可执行的格式，如 cjs
  },
  plugins: [
    run() // 构建完成后自动运行 dist/bundle.js
  ]
};
```

```bash
rollup -c --watch
```

注意事项
- 仅适用于 Node.js 环境可执行的 bundle（通常为 format: 'cjs' 或 'esm' 且 Node 支持）。
- 不适用于浏览器端代码（因为插件是在 Node 中 spawn 子进程运行 bundle）。
- 如果 bundle 有长时间运行（如服务器），可能需要手动终止进程，或结合其他工具（如 nodemon）管理。

总结：@rollup/plugin-run 是一个提升本地开发效率的轻量级工具，特别适合快速迭代的脚本或服务端应用开发。
