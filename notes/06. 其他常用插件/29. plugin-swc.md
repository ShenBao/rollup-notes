# plugin-swc

@rollup/plugin-swc 是一个用于在 Rollup 构建流程中使用 SWC （Speedy Web Compiler）进行 JavaScript/TypeScript 编译的插件。相比 Babel，SWC 是用 Rust 编写的，编译速度更快，适合大型项目或对构建性能有较高要求的场景。


```bash
npm install @swc/core @rollup/plugin-swc --save-dev
```

```js
import swc from '@rollup/plugin-swc';

import swc from '@rollup/plugin-swc';

export default {
  input: 'src/index.ts',
  output: {
    file: 'dist/bundle.js',
    format: 'esm'
  },
  plugins: [
    swc({
      // SWC 配置项
      jsc: {
        target: 'es2020',
        parser: {
          syntax: 'typescript',
          tsx: true,
        },
        transform: {
          react: {
            runtime: 'automatic',
          },
        },
      },
      sourceMaps: true,
    }),
  ],
};
```

@rollup/plugin-swc 的配置直接透传给 SWC 的 transformSync 方法，因此其选项与 SWC 的 .swcrc 配置一致。

## 编译 TypeScript + React（TSX）

```js
swc({
  jsc: {
    parser: {
      syntax: 'typescript',
      tsx: true,
    },
    transform: {
      react: {
        runtime: 'automatic',
      },
    },
    target: 'es2020',
  },
  module: {
    type: 'es6',
  },
  sourceMaps: true,
})
```

## 启用代码压缩（Minify）

```js
swc({
  minify: true,
  jsc: {
    target: 'es2015',
  },
})
```

## 仅处理 .ts 和 .tsx 文件

```js
swc({
  include: ['**/*.ts', '**/*.tsx'],
  jsc: {
    parser: {
      syntax: 'typescript',
      tsx: true,
    },
    target: 'es2020',
  },
})
```
